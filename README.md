# Shiven Mhatre — Developer Portfolio

A modern, fast, and minimalist personal developer portfolio website designed for **Shiven Mhatre**, a 1st-year B.Tech Computer Science & Engineering undergraduate at **IIIT Bhubaneswar**.

Built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Vite**.

---

## ✨ Features & Highlights

- **Cosmic Aurora Visual Experience**: Rich midnight indigo base (`#0b0d22`), animated 5-color floating aurora orbs, reactive multi-neon particle halos, rainbow accent gradients, and colorful glassmorphism.
- **Authentic Engineering Focus**: Grounded in real projects, programming fundamentals, and continuous learning momentum—free of inflated claims or generic templates.
- **Sections**:
  - **Hero**: Clean name, headline, bio, action buttons, dynamic chips, and an interactive multi-tab developer terminal.
  - **About Me**: Concise story highlighting computer science foundations at IIIT Bhubaneswar and core engineering values.
  - **Technical Skills**: Color-coded categorized skill matrices across Programming Languages, Web Dev, Backend & Data, and Developer Tools.
  - **Featured Projects**:
    - **FinTrack AI** (HTML5, CSS3, JavaScript, Supabase) — [Live Demo](https://fintrack-ai.pages.dev/)
    - **CareerOS** (FastAPI, PostgreSQL, Alembic backend architecture)
    - **ScorePulse** (Next.js sports-data provider architecture & fixtures)
    - **Frosted & Fine Cakes** (Responsive bakery website with live Netlify deployment)
  - **Currently Learning**: Interactive deep-dive into active weekly study topics (C++, DSA, Backend, APIs & Databases, Git, AI/ML).
  - **Education**: IIIT Bhubaneswar B.Tech CSE (2026 – Present).
  - **Contact**: Collaboration pillars, direct email card with instant clipboard copying, email launcher (`shiveniiitbbsr@gmail.com`), and an interactive `contact.sh` mock CLI.
  - **Resume Viewer**: Integrated interactive resume modal with print/save PDF capability.

## 🛠️ Quick Start

### 1. Run Development Server
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```
Generates an optimized, lightning-fast static bundle in `dist/`.

### 3. Check Linting
```bash
npm run lint
```

## 🚀 One-Click Deployment Options

### Vercel
1. Push this repository to your GitHub account (`https://github.com/shivenmhatre23-cell`).
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Vercel automatically detects Vite and deploys with zero configuration!

### Netlify
1. Connect your GitHub repository at [netlify.com](https://netlify.com).
2. Set build command: `npm run build`
3. Set publish directory: `dist`
4. Click **Deploy**.
